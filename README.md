# Spiral Apex

A browser-based 3D racing game prototype built using Vite and Three.js.

Features:
- Descending cylindrical helix track
- Customizable 3D player car with body, accent, and wheel colors
- AI drivers racing around the same spiral course
- Arcade HUD with speed, lap, and ranking
- Chase camera and keyboard controls

## Setup

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open the local URL reported in the terminal.

## Production

npm run build

Then preview with:

npm run preview
